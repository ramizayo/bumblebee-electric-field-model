# Ideal-observer limits on electric field detection by bumblebee hairs under environmental noise and mains interference

This repository contains the Python code used to generate the numerical results, sensitivity tables, and figures for the manuscript:

**"Ideal-observer limits on electric field detection by bumblebee hairs under environmental noise and mains interference"**
*Author: Yoel Ramirez Izarra*
*Affiliation: Universidad Nacional de Ingeniería, Lima, Peru*

## Abstract
Bumblebees detect weak electric fields produced by flowers using mechanosensory hairs. This study formulates the problem as one of optimal detection by an ideal observer. We show that an ideal observer strongly rejects mains-frequency interference in the linear regime, but reveals a more fundamental vulnerability: the mechanical saturation of the hair at field amplitudes between 272 V/m and 1361 V/m, which effectively blinds the bee to biologically relevant fields.
